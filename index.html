App Icon Maker PE

アイコンは、作るものではなく育てるもの。

AI との対話を重ねながら macOS アプリアイコンを育て、.icns / .iconset を書き出すデスクトップアプリ。生成 → 選ぶ → 磨く → 保存、の反復で納得の一点に仕上げます。

FEATURES

主な特徴

├┤ バリコン

プロンプト生成

テキストを書いて Enter。固定のシステム制約で macOS らしい構図に収まります。

▼| ダイオード

3 バリアント

1 回の生成で 3 案を提示。横並びで素早く比較できます。

◉ イヤホン

refine ワークフロー

選んだアイコンを次回の基準にバトンタッチして、磨き上げ続けられます。

⎇ アンテナ

参考画像

スケッチや以前のレンダリングを添えて、構図やスタイルを指定できます。

▦ メーター

.icns / .iconset

全標準サイズのアイコンセットを書き出し。マスクは macOS 側で適用。

〜 回路図

回路図風 UI

鉱石ラジオのスケマティック装飾。VU メーター・バリコン・LC 共振タグ。

前提条件

AI バックエンドOpenAI API キー—
USAGE

使い方

1

説明を書く

例）"blue clipboard with folded corner"

2

参考画像を添える（任意）

構図・スタイルの方向性を模型に伝えます。

3

Generate（Enter）

3 つのプレビューが生成されます。

4

バリアントを選んで磨く

選択したアイコンを基準に refine モードで再生成します。

5

Save

.icns と .iconset を保存。Finder で即確認できます。

npm install → npm run dev  （API 不要の UI 確認は npm run dev:mock）
